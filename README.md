# EDM Lab 홈페이지

한국공학대학교 신소재공학과 환경내구금속연구실(EDM Lab) 홈페이지 소스입니다. https://edm-lab.github.io/

- GitHub Pages 기본 빌드(Jekyll). `main`에 push하면 배포됩니다.
- 콘텐츠: `_data/*.yml`, `_news/*.md` / 디자인: `_layouts`, `_includes`, `assets/`
- 작업 규칙: `CLAUDE.md`, 목표와 계획: `docs/PROJECT_BRIEF.md`, 진행 현황: `docs/PROGRESS.md`

로컬 확인:
```
bundle install
bundle exec jekyll serve
```
